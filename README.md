\## 1. Game Overview



Enchanted Forest is a 2D fantasy platformer set in a magical forest. The player controls the Forest Guardian, explores different platforms, avoids dangerous obstacles, collects magical emerald crystals and unlocks an enchanted portal to complete the level.



The game combines exploration, platforming, magic and adventure in a consistent pixel-art environment.



\## 2. Character Pitch and Backstory



The Forest Guardian is a magical protector responsible for maintaining peace and balance within the Enchanted Forest.



One day, a mysterious darkness spreads throughout the forest, scattering its magical crystals and corrupting its peaceful environment. The Guardian must recover the missing crystals, overcome dangerous obstacles and restore the forest's magic by activating the enchanted portal.



The character's signature abilities are double jumping and performing a magical particle attack.



\## 3. Game Objective



The player's objective is to collect all the emerald crystals scattered throughout the level while avoiding poison mushrooms and thorn hazards.



Once all the crystals are collected, the enchanted portal activates. Entering the activated portal completes the level.



The player starts with five health points and three lives. An activated checkpoint allows the player to respawn without restarting from the beginning.

\## 7. How to Run the Game

2\. Extract the EnchantedForest\_Windows.zip file.

3\. Open the extracted folder.

4\. Run the game's executable (.exe) file.

5\. Click Play Game to begin.



Unity installation is not required to play the standalone build.
